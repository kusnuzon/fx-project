cara pakai singkat
Endpoint yang dipakai

Halaman ini bicara langsung ke wss://ws.derivws.com/websockets/v3?app_id=<id> tanpa autentikasi:

  • {"ticks":"1HZ75V","subscribe":1} — stream harga tiap detik.
  • {"ticks_history":"1HZ75V","count":1500,"end":"latest","style":"ticks"} — isi awal grafik.
  • {"active_symbols":"brief","product_type":"basic"} — daftar simbol + pip.
  • {"ping":1} — ukur latensi.

Referensi: Ticks, Ticks History, Active Symbols.

Kenapa ada mode simulasi?

Sebagian jaringan/ISP memblokir upgrade WebSocket (handshake gagal, mis. HTTP 520). Jika feed live tidak tersambung dalam beberapa detik, halaman otomatis pindah ke simulasi lokal agar semua panel tetap bisa dipelajari. Label mode selalu jujur: LIVE hanya saat data benar-benar datang dari Deriv. app_id default 1089 adalah app publik untuk data pasar; ganti dengan app_id milik Anda bila perlu.

Batasan analisis digit

Digit terakhir diambil dari harga yang diformat sesuai jumlah desimal simbol (mis. 1HZ75V 2 desimal → 1234.50 digit 0). Uji chi-square dan z-score hanya mengukur apakah sampel menyimpang dari seragam; pada RNG sintetis, penyimpangan biasanya kembali ke rata-rata. Tidak ada pola digit yang bisa dipakai sebagai kepastian.
