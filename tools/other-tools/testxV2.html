Cara baca & batasan versi ini

Tanggal input selalu tanggal jadwal WIB. Setiap slot diubah menjadi satu timestamp UTC; posisi planet dan ASC/MC dihitung pada timestamp yang sama, lalu ditampilkan dalam WIB dan jam Luxor. Mengganti mode jam Luxor tidak mengubah posisi langit pada timestamp UTC yang sama.

Mode otomatis mengikuti aturan Africa/Cairo: UTC+2 atau UTC+3 menurut tanggal. Versi ini menyertakan snapshot aturan IANA yang diperiksa 3 Oktober 2026 untuk rentang 2020–2040, sehingga tidak bergantung pada database zona waktu Android yang mungkin lama. Aturan tahun mendatang dapat berubah; aplikasi harus diperbarui bila aturan resmi berubah. Mode UTC+3 tetap hanya untuk menyamai konvensi waktu pada web contoh, bukan selalu jam sipil Luxor.

Model arah masih formula eksperimen V1. Tidak ada backtest, data harga, persen confidence, rule Astrodox tervalidasi, atau kepastian profit. Tidak ada order MT5 maupun sinyal Telegram otomatis. Sebutan “inti” hanya skor absolut tertinggi di dalam window terpanjang. Menonaktifkan model menampilkan DATA, bukan memaksa BUY/SELL.

Belum mencakup Nodes, Chiron, Lilith, rumah astrologi lengkap, atau asteroid. Angka dari layanan lain dapat berbeda bila memakai sidereal, topocentric, mean ecliptic, koordinat, orb, atau acuan waktu berbeda.

Butuh internet untuk memuat Astronomy Engine sekali setiap pembukaan bila belum tersedia di cache. File dapat dipublikasikan sebagai index.html. Tidak memuat font, gambar, akun, API key, atau tracker eksternal.

Aturan model V1 yang dipakai (terbuka, belum tervalidasi)

Hanya aspek antarplanet masuk ke penjumlahan skor. BUY bila skor ≥ 1.15; SELL bila skor ≤ −1.15; di antaranya NEUTRAL atau TRANSITION bila perubahan skor antarslot ≥ 0.55. Bobot berikut diwarisi dari prototype, bukan hasil riset XAUUSD.
